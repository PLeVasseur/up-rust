== Whom this page binds

* The item on this page binds the iceoryx2 binding of the up-rust SEooC, and no other transport.
* It binds no iceoryx2 transport written for another SDK, and adds nothing to the protocol's iceoryx2 chapter.
* An entry of the index below binds whoever its own item binds: the binding, the element, or an integrator that deploys on iceoryx2 and claims the element's safety-assurance scope.

== iceoryx2's service depth comes from deployment data

[.specitem,oft-sid="req~ssr-binding-depth-from-deployment~1",oft-title="iceoryx2's service depth comes from deployment data",oft-needs="impl,utest",oft-tags="SafetyIceoryx2"]
--
The iceoryx2 binding *MUST* take each service's depth from deployment data, and create the service with it.

When it opens a service that already exists, it *MUST* compare that service's depth with the deployment's, and refuse a mismatch at setup, naming the route and both depths.
--

[horizontal]
ASIL:: B
Allocated to:: the iceoryx2 binding
Verification:: test (services created in both start orders; a stale depth refused)
Status:: Draft

*Rationale.*

== What other items say about iceoryx2 [[index]]

Some items of other pages name iceoryx2: for a restriction that only iceoryx2 has, as the transport a general rule was written for, or as an example.
Each clause stays in its own item at this revision, and that item governs.
This index lists the clauses so that a deployment on iceoryx2 finds them in one place.
It adds no duty.
