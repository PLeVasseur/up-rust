== Overview

NOTE: The uProtocol Communication Layer (uP-L2) defines the message patterns (pub/sub, notification, and RPC) and APIs used by uEntities, such as applications and services, as well as the routing and dispatching rules for transferring messages across distributed heterogeneous systems. 

.uP-L2 Sections
[cols="1,4"]
|===
|Section | Description

| xref:api.adoc[*APIs*]
|  Communication Layer API that allows developers of uEntities, such as applications and services, to employ the pub/sub, notification and RPC messaging patterns.

| xref:dispatchers/README.adoc[*Dispatchers*]
| The dispatcher uEntities defined in xref:dispatchers/README.adoc#dispatcher-types[Types of Dispatchers].

|===

== Communication-Layer Chapters for the up-rust SEooC and Owned-Frame Contracts

[NOTE]
====
* *Contract-family membership.*
The classic Communication Layer APIs (`LanguageLibrary`, `CommunicationLayerImpl`) live in xref:api.adoc[`api.adoc`] and the classic dispatcher rules live in xref:dispatchers/README.adoc[`dispatchers/README.adoc`].
The chapters indexed below also hold communication-layer items of the owned-frame SDK contract (`+req~sdk-owned-frame-*+`, `OwnedFrame*` tags, no ASIL) and the up-rust SEooC requirement family (`+req~ssr-*+` and `+aou~seooc-*+`, `ASIL:: B`, `Safety*` tags).
Filing these contracts under `up-l2/` neither merges the three families nor binds classic uP-L2 implementations or SDKs of other languages: whom each item binds, and when a scoped replacement takes effect for a named part, is stated in xref:../contract-generations.adoc[Which requirements an implementation follows] (xref:../contract-generations.adoc#req-ssr-requirements-bind[A requirement binds the actors to which it gives a duty]; xref:../contract-generations.adoc#req-ssr-contract-transition[What a part declares and claims, and when a replacement takes effect]; xref:../contract-generations.adoc#req-ssr-item-reading[How an item is read]; xref:../contract-generations.adoc#req-sdk-owned-frame-contract[The owned-frame SDK contract binds the parts that declare it]).
* *Assumptions of use and safety view.*
Claim-scoped integrator assumptions of use for the up-rust SEooC live in xref:../safety/elements/up-rust/assumptions-of-use.adoc[the element's assumptions of use], and Streamer element scope, crate isolation, memory safety and operating assumptions live in xref:../safety/elements/streamer.adoc[Streamer Safety Element].
Conventions, tags and assurance governance live in xref:../safety/README.adoc[Safety and Assurance View] and xref:../safety/assurance.adoc[Assurance and verification governance].
====
